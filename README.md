# 🤖 AI Code Marketplace

## Premium Code Templates & Components Powered by AI

A modern e-commerce marketplace for buying and selling production-ready code templates, components, and full-stack projects.

### 🚀 Features

- ✨ Beautiful, modern UI with Framer Motion animations
- 🛒 Shopping cart and checkout system
- 💳 Stripe payment integration (Ready)
- 🎯 Product filtering and categories
- ⭐ Ratings and reviews system
- 📦 Download management
- 🔐 User authentication (Ready)
- 📱 Fully responsive design
- 🎨 Dark theme optimized for developers
- ⚡ Lightning-fast performance

### 🛠️ Tech Stack

- **Frontend:** Next.js 14, React, TypeScript
- **Styling:** Tailwind CSS, Framer Motion
- **Payment:** Stripe
- **Database:** MongoDB (Ready)
- **Deployment:** Vercel

### 📦 Installation

```bash
# Clone repository
git clone https://github.com/yourusername/ai-code-marketplace.git
cd ai-code-marketplace

# Install dependencies
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000`

### 📝 Environment Variables

Create `.env.local`:

```
NEXT_PUBLIC_STRIPE_KEY=your_stripe_key
STRIPE_SECRET_KEY=your_stripe_secret
NEXT_PUBLIC_API_URL=http://localhost:3000
```

### 🚀 Deployment

Deploy to Vercel:

```bash
npm install -g vercel
vercel
```
